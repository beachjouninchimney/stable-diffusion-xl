# Stable Diffusion XL

### Stability AI's flagship high-resolution image model

Stable Diffusion XL (SDXL) is Stability AI's most powerful open image generation model, producing 1024×1024 images with exceptional detail, prompt adherence, and photorealism. The gold standard for open-source image generation.

<br>

---

## Features

| | |
|:---|:---|
| **1024×1024 Native** | Generate high-resolution images without quality-degrading upscaling |
| **Two-Stage Pipeline** | Base + Refiner pipeline for maximum detail and coherence |
| **Open Weights** | Fully open model — run locally, fine-tune, and deploy commercially |
| **Rich Ecosystem** | Supported by every major SD interface including ComfyUI and Forge |
